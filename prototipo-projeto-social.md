# Prompt para o Codex — Protótipo de Projeto Social

Crie um novo protótipo de landing page para **projetos sociais**, usando como exemplo real o projeto **Karatê Social**, sem alterar ou quebrar os protótipos já existentes no repositório.

## Contexto do projeto

O site principal já está publicado em:

`https://cassianolamarc.com.br/`

Existe uma central de protótipos em:

`https://cassianolamarc.com.br/prototipos/`

O novo protótipo deve ser criado em:

`/prototipos/projeto-social/`

e ficar acessível em:

`https://cassianolamarc.com.br/prototipos/projeto-social/`

Além da nova landing page, atualize a central `/prototipos/` para adicionar um card **Projetos Sociais**, direcionando para esse novo protótipo. Preserve integralmente os cards e protótipos que já existirem.

## Referência visual obrigatória

Use a **imagem anexada a este prompt** como principal referência visual para a criação da página.

- Analise cores, composição, proporções, fotografia, tipografia, hierarquia e clima visual da referência.
- Reinterprete o visual para uma landing page completa, moderna e responsiva; não é necessário fazer uma cópia literal.
- Aproveite a identidade do Karatê Social presente na imagem, quando houver.
- A página precisa funcionar muito bem tanto no desktop quanto no celular.
- Se a imagem tiver elementos adequados para hero/banner, use-a ou reproduza a mesma linguagem visual sem distorcê-la.

Não invente endereço, horários, quantidade de alunos, anos de atuação, número de beneficiados, títulos, certificados, patrocinadores, valores arrecadados, depoimentos, CNPJ, chave PIX ou qualquer outra informação como se fosse um fato do Karatê Social.

Se algum desses elementos for útil ao layout, use um conteúdo claramente demonstrativo/placeholder ou omita o dado. Informações adicionais só podem ser tratadas como reais quando estiverem explicitamente presentes na imagem fornecida ou nos dados deste prompt.

## Objetivo da página

A landing page precisa fazer o visitante entender rapidamente:

1. o que é o projeto;
2. quem pode participar;
3. qual é a proposta social;
4. como entrar em contato ou participar;
5. como uma pessoa ou empresa pode apoiar o projeto;
6. como acompanhar as atividades pelo Instagram.

O site deve transmitir **acolhimento, transformação, disciplina, comunidade, confiança e impacto social**, sem parecer um site comercial de academia de artes marciais.

## Hero section

Crie uma abertura de forte impacto visual baseada na imagem anexada.

Sugestão de estrutura textual — ajuste livremente para alcançar uma redação melhor:

**Karatê que ensina muito além do esporte.**

Texto de apoio voltado a disciplina, união, desenvolvimento pessoal e construção de comunidade por meio do karatê.

CTAs principais:

- **Quero participar** → WhatsApp
- **Quero apoiar o projeto** → rolar até a seção de apoio

Inclua também acesso claro ao Instagram.

No mobile, garanta que headline, imagem e botões apareçam com boa hierarquia sem exigir zoom e sem cortes ruins na imagem.

## Seção — Sobre o projeto

Apresente o **Karatê Social** como um grupo social aberto para crianças e adultos e explique, com texto institucional bem escrito, como o esporte pode ser uma ferramenta para promover valores como disciplina, respeito, união, convivência e desenvolvimento pessoal.

Não atribua ao projeto estatísticas ou resultados específicos que não foram fornecidos.

## Seção — Mais que karatê

Crie cards visuais para apresentar pilares como:

- Disciplina
- Respeito
- União
- Desenvolvimento
- Comunidade
- Esporte

Use ícones consistentes e profissionais. Os cards devem ter textos curtos e humanos, evitando frases genéricas de IA.

## Seção — Para crianças e adultos

Mostre visualmente que o projeto é aberto a públicos diferentes.

Pode dividir a seção em dois blocos:

### Crianças

Foque em convivência, disciplina, coordenação, confiança e aprendizado de valores, evitando promessas absolutas.

### Adultos

Foque em prática esportiva, disciplina, bem-estar, aprendizado e integração com a comunidade.

CTA ao final: **Fale com o projeto e saiba como participar**.

## Seção — O projeto em ação

Crie uma galeria moderna e responsiva para fotos reais de:

- treinos;
- aulas;
- eventos;
- alunos;
- equipe;
- atividades comunitárias.

Como nem todas as imagens estarão disponíveis durante a implementação, organize os assets de forma simples para que eu possa substituir as fotos posteriormente sem alterar o layout.

Não reutilize uma única imagem repetidamente apenas para preencher espaço.

## Seção — Faça parte

Crie uma área com opções claras para diferentes tipos de envolvimento:

- **Quero participar** — entrar em contato pelo WhatsApp;
- **Quero ser voluntário** — contato pelo WhatsApp;
- **Quero apoiar** — direcionar para a seção de apoio/contato;
- **Quero ser parceiro** — voltado também para empresas e instituições.

Os textos podem mencionar apoio com materiais, estrutura, divulgação ou parceria institucional de maneira genérica, sem afirmar que o Karatê Social atualmente aceita uma modalidade específica que não foi confirmada.

## Seção — Apoie este projeto

Crie uma seção emocional, porém sóbria, incentivando pessoas e empresas a entrarem em contato para conhecer formas de apoiar a iniciativa.

**Não invente PIX, dados bancários ou botão de pagamento.**

CTA:

**Quero saber como apoiar** → `https://wa.me/5571988440526`

Essa seção deve estar pronta para futuramente receber PIX, QR Code, plataforma de doação ou patrocinadores, mas esses elementos não devem ser simulados como dados reais agora.

## Identidade visual

A imagem anexada é a principal referência. A partir dela:

- extraia uma paleta coerente;
- mantenha contraste adequado;
- use bastante espaço em branco quando combinar com a referência;
- tenha aparência contemporânea e humana;
- valorize fotografias reais do projeto;
- evite aparência de template genérico;
- evite excesso de animações, gradientes e efeitos que desviem atenção da causa.

A página deve ter personalidade de **projeto social/esportivo**, não de e-commerce ou academia premium.

## Responsividade e compatibilidade

O layout deve ser desenvolvido mobile-first e testado visualmente nos principais tamanhos:

- celulares pequenos;
- celulares atuais;
- tablets;
- notebook;
- desktop largo.

Evite overflow horizontal, textos minúsculos, cards espremidos, imagens deformadas e botões pequenos demais para toque.

## Performance

- Otimize imagens e utilize formatos modernos quando possível.
- Use `loading="lazy"` nas imagens fora do hero.
- Reserve dimensões das imagens para reduzir layout shift.
- Não adicione bibliotecas pesadas sem necessidade.
- Animações devem ser leves e respeitar `prefers-reduced-motion`.
- Evite vídeo autoplay e embeds externos pesados.

## Acessibilidade

- HTML semântico.
- Navegação por teclado.
- Estados de foco visíveis.
- `aria-label` em botões apenas com ícones.
- `alt` adequado nas imagens.
- Contraste legível.
- Hierarquia correta de headings.
- Respeitar `prefers-reduced-motion`.

## SEO do protótipo

Como esta página é uma demonstração dentro da central, adicione:

```html
<meta name="robots" content="noindex, nofollow">
```

Inclua `title`, `description`, favicon e metadados básicos coerentes com o protótipo, mas não tente posicionar a demo no Google.

## Atualização da central de protótipos

O card deve:

- ter imagem/thumbnail coerente com projeto social;

- apontar para `/prototipos/projeto-social/`;

Antes de editar, inspecione a estrutura atual do repositório.

- o funcionamento de `cassianolamarc.com.br/`;
